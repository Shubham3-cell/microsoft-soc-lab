# Microsoft SOC Lab

## Goal

Build an end-to-end Microsoft Security Operations Lab focused on:

- KQL
- Microsoft Sentinel
- Defender XDR
- Threat Hunting
- Detection Engineering
- Incident Response

## Planned Architecture

```text
Linux VM
    ↓
Microsoft Sentinel
    ↓
KQL Hunting Queries
    ↓
Analytics Rules
    ↓
Incident Response
```

## Repository Structure

/kql
Threat hunting and KQL queries

/hunts
Documented hunting scenarios

/detections
Analytics Rules and Sigma Rules

/reports
Incident investigations and case studies

/architecture
Architecture diagrams

/notes
Study notes and learning journal
